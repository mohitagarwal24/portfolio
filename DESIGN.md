## Build Lab behavior

Drop a project from above through the top edge of the computer, click Try Build Lab, or press B on a focused project pill. The project shrinks into the screen and disappears from the pile until reset. The short preview animation ends with an Explore action that opens the existing project report. It does not compile, deploy or execute a project repository. The skill disks are free dynamic bodies that fall and bounce, including after a long held drag. Reset cancels an in-progress preview, restores absorbed projects and resets the physics. Clicking/Enter on a pill still opens its report directly. All other existing navigation, skill controls, filters, search, contact composition and dialogs remain available.
